# 📊 Avaliação de Modelo com Regressão Logística

Este projeto demonstra o treinamento de um modelo de classificação utilizando Regressão Logística e o cálculo de métricas de avaliação em Python.

## 🚀 Funcionalidades

- Geração de dados sintéticos para classificação
- Treinamento de modelo com Regressão Logística
- Cálculo das métricas:
  - Acurácia
  - Precisão
  - Recall
  - F1-Score
- Exibição da matriz de confusão
- Relatório completo de classificação
- Visualização com heatmap

## 🛠️ Tecnologias Utilizadas

- Python 3.x  
- numpy  
- scikit-learn  
- matplotlib  
- seaborn  

## 📂 Estrutura do Projeto

## ▶️ Como Executar

1. git clone https://github.com/lg-devhub/metrics-tests-calculation.git
2. cd seu-repositorio
3. python -m venv venv
4. venv\Scripts\Activate.ps1
5. pip install numpy scikit-learn matplotlib seaborn
